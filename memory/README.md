# memory

Project notes for working with Claude Code on arch-boki-logout. This folder
is part of the repo so it travels with the project and is visible/editable
like any other file.

- [overview.md](overview.md) — what the project is, architecture, key files
- [repo-setup.md](repo-setup.md) — GitHub remote, push.sh / set-git-cred.sh
- [session-log.md](session-log.md) — running log of work sessions, newest first

## Session convention

- Type **"start session"** — Claude reads this folder to re-orient before
  doing anything else.
- Type **"end session"** — Claude appends a summary of the conversation to
  [session-log.md](session-log.md), and updates [overview.md](overview.md) /
  [repo-setup.md](repo-setup.md) if anything about the project changed.
